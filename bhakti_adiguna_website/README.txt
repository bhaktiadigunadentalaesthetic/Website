# Bhakti Adiguna Dental Aesthetic Website

Struktur file:

- `index.html` — struktur halaman
- `css/style.css` — seluruh styling website
- `js/script.js` — fungsi carousel, autoplay, tombol navigasi, dot indicator, dan swipe mobile
- `images/Logo.png` — logo klinik yang diberikan pengguna

## Foto website
Foto carousel dan foto bagian Tentang Kami pada source saat ini masih menggunakan URL Unsplash seperti pada desain awal. Folder `images` disiapkan untuk menyimpan foto lokal. Jika ingin semuanya offline, simpan foto dengan nama `hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg`, dan `about.jpg`, lalu ubah URL gambar di `css/style.css` dan `index.html` menjadi path lokal.
